# Agentic Dev Studio — Frontend Component Map

This is the frontend client for the **Agentic Dev Studio**, engineered using **Next.js**, **React**, **Tailwind CSS**, and **Geist Fonts**. 

It provides an interactive, manufacturing-themed control cockpit where users can design, build, and debug autonomous projects.

## Directory Structure

```
frontend/
├── package.json
├── tsconfig.json
└── src/
    └── app/
        ├── page.tsx          # Main state container & layout coordinator
        ├── layout.tsx        # Top-level viewport shell & Font mappings
        ├── globals.css       # Core design styles & Blueprint grid
        ├── types.ts          # Type declarations
        └── components/       # UI module components
            ├── Sidebar.tsx
            ├── DesignChat.tsx
            ├── SpecViewer.tsx
            ├── Terminal.tsx
            ├── AgentResult.tsx
            └── DevChat.tsx
```

---

## Core Client Files

### 1. `page.tsx` (State Coordinator)
Acts as the global state machine for the application. Coordinates:
*   FastAPI settings sync on mount.
*   Server-Sent Events (SSE) log parsing & streaming.
*   HITL command approval actions.
*   Synchronizing the application specification Markdown across both `DesignChat` and `SpecViewer`.

### 2. `layout.tsx` (Root Shell)
Configures Next.js SEO metadata titles (`Agentic Dev Studio`) and registers the high-tech, geometric **Geist Sans** and **Geist Mono** variable fonts as the system font families.

### 3. `globals.css` (Industrial Style System)
Houses our complete visual token catalog:
*   **Colors**: Slate Matte Black (`#0F0F11`), Crimson Red (`#E51937`), and Industrial Carbon Gray (`#1F1F23`).
*   **`.bg-grid`**: Adds our high-precision blueprint drafting grid pattern behind the layout.
*   **`.industrial-border`**: Adds solid high-contrast crimson accents to control panels.
*   **Scrollbars**: Configures fine-tuned sleek scroll tracks to maximize UI space.

### 4. `types.ts`
Establishes clear TypeScript type models representing SSE telemetry blocks, shell streams, and tool call logs.

## Workspace Components (`components/`)

### 1. `Sidebar.tsx`
Left-aligned cockpit panel. Hosts configurations for providers (OpenAI, Google), key model inputs, custom workspace folders, and live HITL approval toggles.

### 2. `DesignChat.tsx`
An interface to chat with the lead design agent. Supports rich media, paste-to-attach clipboard images, and structured PDF specs.

### 3. `SpecViewer.tsx`
Split-pane panel allowing users to toggle between a live Markdown view of their project's blueprint or edit the raw specifications manually before triggering construction.

### 4. `Terminal.tsx`
A virtual BASH console that streams the agent's real-time internal thoughts (`Thought:`/`Action:` patterns), shell subprocess outputs, tool usages, and hosts interactive buttons to approve or reject pending terminal calls.

### 5. `AgentResult.tsx`
A dedicated summary tray displaying the final code artifacts and verification results generated by the agent upon task completion.

### 6. `DevChat.tsx`
Engineering workspace assistant that operates in two modes:
*   `Ask Mode`: Standard diagnostic chat to ask questions regarding the compiled code base.
*   `Apply Mode`: Allows description of custom patches. Displays the agent's proposed plan, waiting for explicit user confirmation (`Proceed`) before modifying files.
